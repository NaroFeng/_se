FOCUS PROJECT

焦點全端專案｜Cloudflare POS 點餐系統

唯一一個真正「上雲」的專案：同一份後端程式碼，同時跑在本機 Node.js 與 Cloudflare Worker 兩種執行環境上， 線上可直接操作，示範時不需要架任何環境。

已上雲 Live Demo · v1.2.0

POS ＆ Online Ordering System

全端上雲的雙軌架構 POS 點餐系統 —— 同一份 src/ 支援本機與雲端兩種執行環境。

  • 雙軌架構：本機走 Node.js + node:sqlite + 磁碟 uploads/；雲端走 workerd + D1 base64 儲存 + Workers Static Assets。
  • 安全設計：bcrypt 憑證驗證（明文格式一律視為無效）、pin_lookup SHA-256 索引加速登入、ALLOW_REMOTE_ADMIN 遠端寫入隔離與權限降級。
  • 工程化：自建冪等遷移執行器（schema_migrations 記錄已套用檔案）、Unsplash 商品圖自動補齊。
  • 權限模型：Boss／Store Manager／Supervisor／Staff 四階級，權限由 permissions ＋ role_permissions 資料表驅動，前端動態渲染、後端 API 再驗一次。
